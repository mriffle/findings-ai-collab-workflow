Get started

Install & initialize

Add the plugin, set up a project-local Python, and scaffold your study — the engine is shared; your project holds only data and derived state.

What happens

  1. Install the plugin. Add this repo as a marketplace, install findings-workflow, then /reload-plugins (or restart Claude Code).
  2. Set up Python (≥ 3.11). setup-env detects an existing interpreter, or — with your consent — installs one into the project via uv: zero global footprint, a committed uv.lock.
  3. Scaffold the project. init creates the layout, seeds the color registry, initializes the findings graph and workflow state, and writes the project CLAUDE.md.
The load-bearing boundary The plugin is the engine — shared, versioned, carries no data. Your project is the data + derived state, generated per study.
