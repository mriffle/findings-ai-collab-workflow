STAGE 5

Independent validation

Promote a candidate finding toward validated through blinded, independent re-derivation.

What happens

  1. Pick the mode — analytic replication (same data), or data replication (held-out / orthogonal data → confirmatory).
  2. Build the blind task — derived mechanically from the finding's fields, with verdict / evidence / summary stripped.
  3. Pre-specify the concordance criterion — before the verifier runs (deciding "close enough" afterward reintroduces forking paths).
  4. Dispatch the verifier — clean context, no history; re-derives from scratch; never sees the answer.
  5. Judge concordance & record the outcome.
The validated bar integrity sign-off + computational reproduction + blinded analytic replication + the phase bar. Promotion is never silent — the scientist accepts.
