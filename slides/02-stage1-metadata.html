STAGE 1 · FIRST CODE RUNS

Understand the metadata

A verified understanding of the experiment — generated from evidence in code, never hand-asserted.

What happens

  1. Infer & validate every column — meanings, types, ranges, uniqueness. Fail loud on anything inconsistent.
  2. Identify control samples — pooled QC, reference / bridge, standards, blanks. Classify every sample experimental vs control.
  3. Test the inferences in code — relationships that should hold; independence from batch, run-order, and covariates (bias-corrected Cramér's V).
  4. Characterize the cohort — per-variable distributions, pairwise crosstabs, a publishable "Table 1".
  5. Record material imbalance / skew / confounds as caveat findings.
Human checkpoint The scientist confirms the inferred column meanings and the experimental / control split before the file is written.
