What the Findings Workflow is

A shipped set of opinions

The Findings Workflow is a Claude Code plugin — the shared engine behind the whole process. It's built from four kinds of parts, and it ships with vetted templates for the analysis itself.

The workers

Agents

Specialized AI workers, each in its own clean context, doing one job — writing code, reviewing it, running stats, validating a result.

The know-how

Skills

Procedures the AI pulls in on demand — the right, vetted way to do the task at hand.

The steps

Commands

What you run — one per stage, walking the study from setup to final report.

The guardrails

Hooks

Automatic checks that enforce the rules — not just suggest them. Deterministic gates.

Ships with — the analysis itself

Templates — tested opinions, not black boxes

Vetted, tested analysis scripts and data loaders — not code to run blindly. They're robust, defensible starting points, copied into your project and adapted to your data. Each one encodes how a step should be done.

Really, it's a set of opinions — how to analyze proteomics data well, distilled from years of experience and shipped as robust, tested, reviewable defaults.
