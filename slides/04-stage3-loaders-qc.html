STAGE 3 · INTEGRITY GATE

Loaders, pairing & QC

Build tested loaders, verify the read against the source, pair every sample exactly, and produce QC — the gate that unlocks all analysis.

What happens

  1. Build robust, tested loaders — unit + property + planted-truth + edge-case tests.
  2. Verify the read on the real file — counts reconcile, spot-check cells, orientation confirmed, identifier integrity, scale recorded.
  3. Pair sample ↔ metadata exactly — no orphans or duplicates (fuzzy matches → human checkpoint); the experimental / control split is certified.
  4. QC report — seven lib/figures/ families, one figure-generator + figure-reviewer each; normalization applied here first, batch correction previewed when a ≥ 2-batch axis exists.
The gate Passes only when loader tests pass, the read is verified, pairing is exact, and the scientist signs off. No Stage 4 analysis before this — a silent loader error is common-mode and defeats validation.
