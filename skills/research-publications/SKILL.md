# Researching scientific publications

Goal: durable, specific, **verifiable** literature support — never a vague gesture at "the literature." Authoritative rule: the references invariant (doc 04.5).

## Procedure

1. **Scope the question** tightly (from the librarian). One question, not a field survey.
2. **Find primary sources.** Prefer peer-reviewed primary literature over reviews for specific claims (reviews are useful for orientation and to find primaries). Use web search + authoritative indexes; resolve to a **DOI or PMID**.
3. **Read enough to attribute correctly.** For each claim you'll record, confirm the source actually states it — read the relevant section, not just the title/abstract. Note effect directions and any conditions/caveats the source places on the claim.
4. **Distinguish status:** established / well-supported vs contested / preliminary / single-study. Say which.
5. **Record each claim with its source:** the specific `claim` text and the reference (`doi:`/`pmid:`). Multiple claims may share a source; each claim still names the source that supports *it*.

## Cite like the reviewer will check

Every reference will be independently verified to **exist** and to **support its claim**. So:

- Use resolvable identifiers (DOI/PMID; a stable URL only when no DOI/PMID exists).
- Never invent, guess, or approximate a citation. If you can't find a source for a claim, record the claim as **unverified** rather than attaching a plausible-looking citation.
- Quote or closely paraphrase what the source says when attribution is subtle.

Write the result into a research-finding (`templates/research-finding.md`); it goes to the research-reviewer before entering the corpus.
